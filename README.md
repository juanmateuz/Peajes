# Ruta y peajes Colombia

Planificador de rutas con peajes en Colombia. Los peajes se toman en vivo del tablero público de Supertransporte; las rutas vienen de OSRM y OpenStreetMap.

Página: https://juanmateuz.github.io/Peajes/

Las tarifas son estimadas: confirma con el concesionario, la ANI o el INVÍAS.
